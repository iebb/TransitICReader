# iPhone, iPad and Mac Catalyst app

Open the root `CardBal.xcodeproj`. The project entry point remains stable for
Xcode Cloud; its sources and runtime resources are under `ios/CardBal`.

See the root README and [development guide](../docs/development/testing.md).

iPad and macOS require an external NFC card reader. On iPhone, choose iPhone NFC or External Reader explicitly. See [external-reader setup](../docs/development/external-nfc-readers.md).
