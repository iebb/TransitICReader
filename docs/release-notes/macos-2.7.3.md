# CardBal 2.7.3 for Mac

- Madrid: read Tarjeta Transporte Público passes and multi-trip tickets with a compatible USB reader, including zones, validity, remaining trips and profile. These cards can only be read through the Consorcio de Transportes de Madrid's service; turn off Madrid Online in Settings > Privacy to stop this.

Requires macOS 13 or later and a compatible USB NFC / CCID reader.

Download `CardBal-2.7.3-macOS.zip`, open it, and move CardBal to Applications.
