# CardBal 2.6.4 for Mac

The iPhone App Clip adds a quick card balance check from a link. Mac card reading continues to use an external reader.

Requires macOS 13 or later and a compatible USB NFC / CCID reader.

Download and SHA-256 checksum: the release assets at https://github.com/iebb/TransitICReader/releases/tag/macos-v2.6.4 include the Mac download and its checksum.
