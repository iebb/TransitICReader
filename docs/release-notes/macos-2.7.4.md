# CardBal 2.7.4 for Mac

- Boston: read a CharlieCard with a compatible USB NFC reader, showing the balance, card number, recent trips with bus, subway or ticket-machine and fare, and the issue and expiry dates.

Requires macOS 13 or later and a compatible USB NFC / CCID reader.

Download `CardBal-2.7.4-macOS.zip`, open it, and move CardBal to Applications.
