# CardBal 2.7.7 for Mac

- Cards that carry Macau Pass together with Lingnan Pass or Shenzhen Tong now also show the Lingnan Pass or Shenzhen Tong balance when it can be read with a USB reader.

Requires macOS 13 or later and a compatible USB NFC / CCID reader.

Download `CardBal-2.7.7-macOS.zip`, open it, and move CardBal to Applications.
