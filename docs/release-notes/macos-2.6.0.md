CardBal 2.6.0 for macOS keeps the Mac app in step with CardBal 2.6.0 for
iPhone. It is a universal Mac Catalyst app for Apple silicon and Intel Macs,
signed with Developer ID and notarized by Apple.

Download `CardBal-2.6.0-macOS.zip`, open it, and move CardBal to Applications.
CardBal requires macOS 13 Ventura or later.
A compatible external USB NFC / CCID reader is required to scan cards on a Mac.

There are no new Mac features in this release. The headline fix in 2.6.0,
reading La Carte (Lignes d'Azur) again, applies to the iPhone's built-in NFC.
On a Mac with a USB reader, La Carte is still read by the general Calypso
reader, unchanged from 2.5.2. Lisbon Zapping, the Chinese local cards and the
card-face pickers were already in 2.5.2 for Mac.

The repository and this tag include the application source, build instructions
and third-party code and data license notices. `SHA256SUMS.txt` contains the
download checksum.
