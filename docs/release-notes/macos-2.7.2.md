# CardBal 2.7.2 for Mac

- More Singapore EZ-Link and other CEPAS cards can be read with a compatible USB reader. If a card still can't be read, Copy Debug Log in Settings > Troubleshooting records why.

Requires macOS 13 or later and a compatible USB NFC / CCID reader.

Download `CardBal-2.7.2-macOS.zip`, open it, and move CardBal to Applications.
