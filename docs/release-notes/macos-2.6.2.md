CardBal 2.6.2 for macOS keeps the Mac app in step with CardBal 2.6.2 for
iPhone. It is a universal Mac Catalyst app for Apple silicon and Intel Macs,
signed with Developer ID and notarized by Apple.

Download `CardBal-2.6.2-macOS.zip`, open it, and move CardBal to Applications.
CardBal requires macOS 13 Ventura or later.
A compatible external USB NFC / CCID reader is required to scan cards on a Mac.

New on Mac, as on iPhone:

- Send Feedback in Settings: report a problem or share an idea, with up to four
  screenshots. The app version and Mac model are sent along.
- CardBal now sends crash reports automatically, so crashes can be found and
  fixed sooner. They hold technical details: where in the app the crash
  happened, the app version and the Mac model.

The repository and this tag include the application source, build instructions
and third-party code and data license notices. `SHA256SUMS.txt` contains the
download checksum.
