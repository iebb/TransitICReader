# CardBal

[English](README.md) | 简体中文 | [日本語](README.ja.md)

CardBal 是适用于 iPhone、iPad、Mac 和 Android 的交通 IC 卡读卡应用。
查看卡片余额、回顾最近的乘车记录，并将多张卡片保存在同一个钱包中。

支持 Suica、PASMO、ICOCA、八达通、T-money、EZL/Cashbee、交通联合、
EZ-Link 等卡片。可读取的余额和记录因卡种而异。

## 功能

- 读取受支持卡片的余额和最近交易
- 自定义卡名、颜色和卡面
- 在有站点数据的情况下，将乘车记录显示在地图上
- 备份钱包，并在 iPhone 和 Android 之间迁移

## 支持平台

| 平台 | 读卡方式 |
| --- | --- |
| iPhone | 内置 NFC 或兼容的外接 USB 读卡器 |
| Android | 设备自带的 NFC 读卡器 |
| iPad 和 Mac | 需要兼容的外接 USB NFC / CCID 读卡器 |
